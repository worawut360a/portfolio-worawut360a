# เอกสารสำหรับนักพัฒนา

ผู้ใช้ทั่วไปอ่าน [README](../README.md) และ [คู่มือใช้งาน](คู่มือใช้งาน.md) พอ
ไฟล์นี้เก็บรายละเอียดทางเทคนิคสำหรับคนที่จะแก้โค้ดต่อ

```
หน้าเว็บ + หลังบ้าน   →  Next.js 15 (App Router) บน Netlify
ฐานข้อมูล             →  Turso (libSQL — SQLite ที่ทำเป็นบริการ)
รูปภาพ + ไฟล์เอกสาร   →  Google Drive (เก็บแค่ FILE ID ในฐานข้อมูล)
หน้าตา                →  Tailwind v4 + app/design.css (ยกมาจากเทมเพลต PHP)
```

## รันบนเครื่อง

```bash
npm install
cp .env.example .env.local          # ค่าเริ่มต้นชี้ไปไฟล์ SQLite บนเครื่อง
npm run db:local                    # สร้าง db/local.sqlite จาก schema + seed-core
npm run setup                       # สร้างบัญชีผู้ดูแล (ถามทีละข้อ)
npm run dev                         # http://localhost:3100
```

`AUTH_SECRET` **ไม่ต้องตั้ง** — ถ้าไม่มี ระบบจะสุ่มให้แล้วเก็บใน `site_settings`
ตั้งเองเฉพาะกรณีที่อยากคุมค่านี้ (ต้องยาว ≥ 32 ตัวอักษร)

## คำสั่งที่มี

| `npm run dev` / `build` / `start` | รัน/บิลด์ (มี `bundle-sql.mjs` ฝัง SQL ลงโค้ดก่อนเสมอ) |

| `npm run export:php` | ย้ายข้อมูลจากเทมเพลต PHP เดิม |

## การแคชหน้าเว็บ

`app/layout.tsx` ตั้ง **`export const revalidate = 3600`** — หน้าสาธารณะถูกเก็บที่ CDN
ไม่ใช่ `force-dynamic` (เคยเป็น แล้วเว็บช้า 1–2 วินาทีต่อคลิก เพราะยิงฐานข้อมูลข้ามทวีปสิบกว่ารอบ)

ความสดของข้อมูลไม่เสีย เพราะทุก server action เรียก `revalidatePath('/', 'layout')`
พอครูกดบันทึก หน้าเว็บอัปเดตทันที ตัวเลข 3600 เป็นแค่ตาข่ายกันพลาด

**ผลที่ตามมา:** หน้าสาธารณะห้ามอ่าน cookie ตรง ๆ ไม่งั้นจะกลายเป็น dynamic ทั้งหน้า
ปุ่มลัดไปหลังบ้านที่โผล่เฉพาะตอนล็อกอิน จึงใช้ `<AdminOnly>` ซึ่งเช็คผ่าน `/api/me` ฝั่งเบราว์เซอร์

## หน้าตา: `app/design.css`

คัดลอกมาจาก `assets/css/app.css` ของเทมเพลต PHP **แก้จากต้นฉบับจุดเดียว** คือตัดวงเล็บปีกกา
ปิดที่เกินมา 5 ตัวท้ายไฟล์ (เบราว์เซอร์มองข้ามให้ แต่ตัวแปล CSS ของ Next แปลไม่ผ่าน)

```css
@import "tailwindcss";
@import "./design.css" layer(components);   /* ← layer() ห้ามลืม */
```

> 🔴 **`layer(components)` สำคัญมาก** ถ้าลืม กฎ `a{color:inherit}` ใน design.css
> จะชนะคลาสสีของ Tailwind **ทุกตัว** เพราะ CSS ให้กฎที่อยู่นอก layer ชนะกฎที่อยู่ใน layer เสมอ
> ไม่ว่า specificity จะเป็นเท่าไหร่ → ลิงก์ที่ใส่ `text-white` จะกลายเป็นสีดำทั้งเว็บ
> (เทมเพลต PHP ไม่เจอปัญหานี้เพราะ Tailwind แบบ CDN ไม่ได้ใส่ layer)

ชื่อธีมของสองระบบไม่ตรงกัน — ฝั่ง Next ใช้ชื่อที่ตรงกับสีจริง แล้ว map ใน `app/globals.css`

| PHP | Next |
|---|---|
| `pink` | `emerald` |
| `mint` | `royal` |
| `lavender` | `maroon` |

## โมเดลสื่อ: `source` + `ref`

ทุกที่ที่เคยเก็บ path ของไฟล์ เปลี่ยนเป็นเก็บ 2 คอลัมน์คู่กัน

| `source` | `ref` เก็บอะไร | ใช้ตอนไหน |
|---|---|---|
| `drive` | Google Drive **FILE ID** | รูปและเอกสารที่ครูแนบเอง |
| `static` | path ใต้ `/public` | รูปตัวอย่างที่มากับเทมเพลต |

**เก็บ ID ไม่เก็บ URL เต็ม** เพราะ `lh3.googleusercontent.com` เป็น endpoint ที่ Google
ไม่ได้ประกาศรองรับ (Google เคยปิด `drive.google.com/uc?export=view` มาแล้ว ตอนนี้คืน 403)
ถ้าวันหนึ่งรูปแบบเปลี่ยน แก้ที่ [`lib/media.ts`](../lib/media.ts) ไฟล์เดียว
ฐานข้อมูลของลูกค้าทุกคนไม่ต้องแตะเลย

**ห้ามประกอบ URL ของ Google เองที่อื่นเด็ดขาด** ให้เรียกผ่าน `imageUrl()` / `fileUrl()` เท่านั้น

ไม่มีคอลัมน์ thumbnail — ย่อที่ปลายทางแทน (`drive` ต่อท้าย `=w400` · `static` ผ่าน Netlify Image CDN)

`avatar_focus_x` / `avatar_focus_y` เก็บจุดโฟกัส 0–100% แล้วใช้ CSS `object-position`
เพราะรูปจาก Drive แก้ไฟล์ต้นทางไม่ได้ จึงครอบตัดแบบเทมเพลต PHP ไม่ได้

## ความปลอดภัย

- JWT เก็บใน cookie แบบ `HttpOnly` + `Secure` + `SameSite=Strict`
- `middleware.ts` เช็คแค่ว่า**มี cookie ไหม** (edge อ่านฐานข้อมูลเพื่อเอา secret ไม่ได้)
- **ทุก Server Action และทุกหน้าใน `/admin` เรียก `requireAdmin()` เป็นบรรทัดแรกเสมอ**
  middleware เป็นแค่ด่านสะดวก ไม่ใช่ระบบความปลอดภัยหลัก
  หน้าใน `/admin` ต้องเรียกเองด้วย เพราะ Next render layout กับ page **พร้อมกัน**
  ถ้าเช็คแค่ใน layout ตัว page จะ render ข้อมูลจริงเสร็จไปแล้วก่อนที่ layout จะ redirect
- `/api/works?admin=1` (รวมฉบับร่าง) ตรวจ session จริงก่อนเสมอ
- บันทึกความพยายามล็อกอินใน `login_attempts` · การแก้ข้อมูลใน `activity_log`
- เปรียบเทียบรหัสผ่านเสมอแม้ไม่พบบัญชี กันการเดาจากเวลาตอบกลับ
- รหัสผ่านที่ hash จาก PHP (`$2y$...`) ใช้ต่อได้เลย

### รหัสกู้คืน

`lib/recovery.ts` — รหัสรูปแบบ `XXXX-XXXX-XXXX` (ตัวอักษร 31 ตัวที่ไม่สับสน ≈ 59 บิต)
เก็บใน `site_settings.recovery_hash` เป็นค่าที่ bcrypt แล้ว **ใช้ได้ครั้งเดียว** ใช้แล้วลบทิ้ง
นับความพยายามรวมกับการล็อกอินปกติ (ผิด 5 ครั้งใน 15 นาทีล็อก) กันไม่ให้เป็นประตูหลังยิงเดา

## โครงไฟล์

```
app/(site)/          หน้าเว็บสาธารณะ (route group แยกจาก /admin ไม่ให้ layout ซ้อนกัน)
app/admin/           หลังบ้าน
app/api/works/       API ค้นหาผลงาน (ใช้โดยหน้าตัวชี้วัดและตารางหลังบ้าน)
app/api/me/          บอกแค่ว่าล็อกอินอยู่ไหม — ให้ปุ่มลัดใช้โดยหน้ายังแคชได้
lib/media.ts         ที่เดียวที่ประกอบ URL ของรูปและไฟล์
lib/queries.ts       ทุก query ของหน้าเว็บ (ตรงกับ Repository.php ของ PHP)
lib/auth.ts          session · ล็อกอิน · จำกัดจำนวนครั้ง · activity log
lib/recovery.ts      รหัสกู้คืน
lib/setup.ts         ตัวติดตั้ง (ใช้ร่วมกันทั้งหน้า /setup และ npm run setup)
components/admin/    คอมโพเนนต์หลังบ้าน (Modal · MediaEditor · ตาราง · โมดัลของแต่ละหน้า)
db/schema.sql        19 ตาราง · 13 ดัชนี
db/seed-core.sql     3 ด้าน + 15 ตัวชี้วัด ตามเกณฑ์ ว9/2564 · ธีม · โปรไฟล์เปล่า
db/seed-demo.sql     ข้อมูลตัวอย่าง 30 ผลงาน · 85 รูป (ชี้ไป public/media/seed/)
```

`bundle-sql.mjs` แปลงไฟล์ `.sql` เป็น `lib/sql-bundle.ts` ตอน dev/build
เพราะ Netlify Functions อ่านไฟล์จากดิสก์ตอนรันไม่ได้

## ย้ายข้อมูลจากเว็บ PHP เดิม

```bash
# จากเทมเพลต SQLite
php scripts/export-from-php.php \
  --sqlite=../portfolio-website-sqlite/database/portfolio.sqlite \
  --uploads=../portfolio-website-sqlite/uploads \
  --out=db/migrated.sql --copy

# จากเว็บตัวจริงที่ใช้ MySQL
php scripts/export-from-php.php \
  --config=../portfolio-website/config/config.php \
  --uploads=../portfolio-website/uploads \
  --out=db/migrated.sql --copy
```

`--copy` คัดลอกรูปเดิมมาไว้ใน `public/media/` ให้ด้วย เว็บใหม่แสดงผลได้ทันที
โดยยังไม่ต้องย้ายอะไรขึ้น Google Drive แล้วค่อยทยอยเปลี่ยนทีละรูปภายหลัง
(สคริปต์นี้ **อ่านอย่างเดียว** ไม่แตะฐานข้อมูลหรือไฟล์ต้นทาง)
