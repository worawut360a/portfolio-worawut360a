# แฟ้มสะสมผลงานครู วPA (e-Portfolio)

เว็บไซต์แฟ้มสะสมผลงานครู ตามหลักเกณฑ์ **วPA ว9/2564** — มีทั้งหน้าเว็บสำหรับให้กรรมการดู
และระบบหลังบ้านให้ครูกรอกข้อมูลเองได้ทั้งหมด

**ใช้ฟรีทั้งหมด ไม่มีค่าเช่าโฮสต์ ไม่ต้องผูกบัตรเครดิต**

| ส่วน | ใช้บริการ |
|---|---|
| หน้าเว็บ + หลังบ้าน | Netlify |
| ฐานข้อมูล | Turso |
| รูปภาพและไฟล์เอกสาร | Google Drive ของคุณเอง |

📖 **[คู่มือใช้งานหลังบ้านสำหรับคุณครู](docs/คู่มือใช้งาน.md)** · 🛠 [เอกสารสำหรับนักพัฒนา](docs/สำหรับนักพัฒนา.md)

---

## สิ่งที่ต้องเตรียม

สมัคร 3 บัญชี ฟรีทั้งหมด แนะนำให้สมัคร Turso กับ Netlify ด้วยปุ่ม **"Sign up with GitHub"**
จะได้ไม่ต้องจำรหัสผ่านหลายชุด

1. [github.com](https://github.com) — เก็บโค้ดเว็บของคุณ
2. [turso.tech](https://turso.tech) — ฐานข้อมูล
3. [netlify.com](https://netlify.com) — ที่รันเว็บและแจกลิงก์

> ทั้งหมดนี้ทำผ่านหน้าเว็บ **ไม่ต้องพิมพ์คำสั่งใด ๆ** ใช้เวลาราว 20 นาที

---

## ติดตั้ง 4 ขั้นตอน

### ขั้นที่ 1 — สร้างฐานข้อมูลที่ Turso

1. เข้า [turso.tech](https://turso.tech) → สมัคร/เข้าสู่ระบบ
2. สร้างฐานข้อมูลใหม่ (Create Database) ตั้งชื่ออะไรก็ได้ เช่น `portfolio`
3. เข้าไปในฐานข้อมูลนั้น หาปุ่มเชื่อมต่อ (Connect) แล้ว **จดค่า 2 อย่างนี้ไว้**

| จดค่านี้ | หน้าตาประมาณนี้ |
|---|---|
| ที่อยู่ฐานข้อมูล | `libsql://portfolio-ชื่อคุณ.turso.io` |
| โทเคน (Token) | ข้อความยาวมาก ๆ ขึ้นต้นด้วย `eyJ...` |

> ⚠️ **คัดลอกโทเคนเก็บไว้ทันที** บางหน้าจอโชว์ให้ดูแค่ครั้งเดียว ถ้าปิดไปแล้วต้องสร้างใหม่

### ขั้นที่ 2 — ก๊อบปี้เทมเพลตเป็นของคุณเอง

ที่หน้า repo นี้บน GitHub กดปุ่มเขียว **"Use this template" → "Create a new repository"**
ตั้งชื่อ repo แล้วกด Create

คุณจะได้โค้ดชุดเดียวกันเป็นของตัวเอง แก้อะไรก็ไม่กระทบต้นฉบับ

### ขั้นที่ 3 — เอาขึ้น Netlify

1. เข้า [app.netlify.com](https://app.netlify.com) → **Add new site** → **Import an existing project**
2. เลือก **GitHub** แล้วเลือก repo ที่เพิ่งสร้างในขั้นที่ 2
3. **ก่อนกด Deploy** เลื่อนหาหัวข้อ **Environment variables** แล้วใส่ค่าที่จดไว้จากขั้นที่ 1

| ช่อง **Key** (พิมพ์ตามนี้เป๊ะ ๆ) | ช่อง **Value** |
|---|---|
| `TURSO_DATABASE_URL` | ที่อยู่ `libsql://...` |
| `TURSO_AUTH_TOKEN` | โทเคนที่จดไว้ |

> 🔴 **จุดที่คนพลาดบ่อยที่สุด** — ช่อง **Key** คือ *ชื่อตัวแปร* ไม่ใช่ที่วางโทเคน
> โทเคนต้องอยู่ในช่อง **Value** เท่านั้น

4. กด **Deploy** รอประมาณ 2–3 นาที จะได้ลิงก์เว็บแบบ `https://ชื่อที่ตั้ง.netlify.app`

การตั้งค่า build ทั้งหมดอยู่ในไฟล์ `netlify.toml` แล้ว **ไม่ต้องกรอกอะไรเพิ่ม**

### ขั้นที่ 4 — ติดตั้งระบบ

เปิด `https://ลิงก์เว็บของคุณ/setup` — หน้านี้จะตรวจให้เองว่าต่อฐานข้อมูลได้หรือยัง
(มีเครื่องหมาย ✓ / ✕ บอกชัดเจน ถ้ายังไม่ผ่านจะบอกว่าต้องแก้อะไร)

กรอก 3 ช่อง แล้วกด **ติดตั้งระบบ**

- **ชื่อผู้ใช้** — ใช้เข้าหลังบ้าน (แนะนำ `admin`)
- **รหัสผ่าน** — อย่างน้อย 8 ตัวอักษร
- **ชื่อ–สกุลของคุณครู**

มีช่องติ๊ก *"ใส่ข้อมูลตัวอย่างมาให้ดูก่อน"* — แนะนำให้ติ๊กไว้ จะได้เห็นว่าเว็บเต็ม ๆ หน้าตาเป็นอย่างไร
แล้วค่อยลบทีหลังในหลังบ้าน

> 🔑 **ติดตั้งเสร็จจะได้ "รหัสกู้คืน" มา 1 ชุด (เช่น `QQE8-BH83-A3U9`)**
> **หน้านี้โชว์ครั้งเดียวเท่านั้น** ให้คัดลอกเก็บไว้ที่ปลอดภัย — ใช้ตั้งรหัสผ่านใหม่ตอนลืมรหัสผ่าน
> ถ้าทำหาย เข้าหลังบ้านแล้วออกใบใหม่ได้ที่หน้า *ตั้งค่าระบบ*

เมื่อติดตั้งเสร็จ **หน้า `/setup` จะปิดตัวเองถาวร** เข้าอีกไม่ได้

> ⏱ ทำขั้นตอนนี้ทันทีหลัง deploy เสร็จ — ระหว่างที่ยังไม่มีบัญชีผู้ดูแล
> ใครที่รู้ที่อยู่เว็บก็เข้าไปตั้งบัญชีแทนคุณได้

**เสร็จแล้ว!** เข้า `https://ลิงก์เว็บของคุณ/login` เพื่อเริ่มกรอกข้อมูลจริง

## หลังติดตั้งเสร็จ ทำอะไรต่อ

อ่าน **[คู่มือใช้งานหลังบ้าน](docs/คู่มือใช้งาน.md)** ได้เลย แต่สรุปสั้น ๆ คือกรอกตามลำดับนี้

1. **โปรไฟล์ครู** — ชื่อ ตำแหน่ง โรงเรียน รูปถ่าย วุฒิการศึกษา
2. **ข้อตกลง PA** — สร้างปีงบประมาณ แล้วกรอกตอนที่ 1–3
3. **ผลงาน** — เข้าทางหน้าข้อตกลง PA → ตอนที่ 2 → กดปุ่ม 📚 ผลงาน ของตัวชี้วัดนั้น
4. **การพัฒนาตนเอง / รางวัล**
5. **ตั้งค่าระบบ** — เลือกธีมสี (มี 3 แบบ)

### เรื่องรูปภาพ — ต้องอ่าน

ระบบนี้ **ไม่มีการอัปโหลดไฟล์** ทุกรูปและทุกเอกสารแนบเป็น *ลิงก์* จาก Google Drive

1. อัปโหลดไฟล์ขึ้น Google Drive ของคุณเอง
2. คลิกขวาที่ไฟล์ → **แชร์** → เปลี่ยนจาก "จำกัด" เป็น **"ทุกคนที่มีลิงก์"**
3. คัดลอกลิงก์ → วางในช่องของหลังบ้าน ระบบจะอ่านรหัสไฟล์ให้เองและโชว์ตัวอย่างทันที

> ⚠️ ถ้าไม่เปลี่ยนเป็น "ทุกคนที่มีลิงก์" **รูปจะไม่ขึ้นบนเว็บ**
> และเพราะไฟล์เป็นสาธารณะ **อย่านำเอกสารที่มีข้อมูลส่วนตัวของนักเรียนขึ้น**

## คำถามที่พบบ่อย

**ลืมรหัสผ่านทำอย่างไร**
เข้าหน้า `/login` กด **"ลืมรหัสผ่าน?"** แล้วกรอกรหัสกู้คืนที่ได้ตอนติดตั้ง
รหัสนี้ใช้ได้ครั้งเดียว ใช้แล้วให้เข้าไปออกใบใหม่ที่หน้า *ตั้งค่าระบบ*
ถ้าทำรหัสกู้คืนหายและยังเข้าหลังบ้านได้อยู่ ให้รีบไปออกใบใหม่ทันที

**ลบข้อมูลตัวอย่างอย่างไร**
เข้าหลังบ้านแล้วลบทีละรายการได้เลย (ผลงาน · การพัฒนาตนเอง · รางวัล · ข้อตกลง PA)
ส่วน 15 ตัวชี้วัดกับ 3 ด้าน เป็นโครงตามเกณฑ์ ว9/2564 ห้ามลบ

**เปลี่ยนที่อยู่เว็บให้สวยขึ้นได้ไหม**
ได้ ที่ Netlify → Site configuration → Change site name (เปลี่ยนส่วนหน้า `.netlify.app`)
หรือถ้ามีโดเมนของตัวเอง ก็ผูกได้ที่ Domain management

**เปลี่ยนสีเว็บได้ไหม**
ได้ ที่หน้า *ตั้งค่าระบบ* มี 3 ธีม — เขียวมรกต · น้ำเงิน · แดงเลือดหมู กดแล้วเปลี่ยนทันที

**แก้ข้อมูลแล้วหน้าเว็บไม่เปลี่ยน**
กด Ctrl+F5 (หรือ Cmd+Shift+R) เพื่อล้างแคชของเบราว์เซอร์ดูก่อน
ปกติหน้าเว็บจะอัปเดตให้อัตโนมัติทันทีที่กดบันทึกในหลังบ้าน

**สำรองข้อมูลอย่างไร**
รูปและไฟล์อยู่ใน Google Drive ของคุณเองอยู่แล้ว ส่วนข้อความทั้งหมดอยู่ที่ Turso
ซึ่งมีเครื่องมือสำรองให้ในหน้าเว็บของ Turso เอง

**เทมเพลตออกเวอร์ชันใหม่ แล้วเว็บของฉันจะได้ด้วยไหม**
ไม่อัตโนมัติ เพราะ "Use this template" เป็นการก๊อบครั้งเดียวไม่ผูกกับต้นฉบับ
ถ้าอยากได้ของใหม่ต้องดึงมาเอง หรือให้ผู้ที่ติดตั้งให้คุณช่วยดำเนินการ

## ความปลอดภัย

- รหัสผ่านเก็บแบบ **BCRYPT** ย้อนกลับเป็นรหัสจริงไม่ได้
- เข้าสู่ระบบผิดเกิน 5 ครั้งใน 15 นาที ระบบจะล็อกชั่วคราว (รวมถึงการใช้รหัสกู้คืนด้วย)
- ทุกคำสั่งที่เขียนข้อมูลตรวจสิทธิ์ฝั่งเซิร์ฟเวอร์เสมอ ไม่ได้เช็กแค่ที่หน้าจอ
- บันทึกทุกการแก้ไขไว้ในหน้า *ตั้งค่าระบบ* → บันทึกการใช้งาน
